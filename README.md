# 📊 HR Attrition Analysis Dashboard

> **Turning HR data into meaningful workforce insights.**

An interactive **HR Attrition Analysis Dashboard** developed using **Microsoft Power BI** to analyze employee attrition across **age, salary, education, working years, gender, and department**.

This project transforms raw HR data into an interactive business intelligence dashboard that helps users explore employee attrition patterns from multiple perspectives.

---

## 🖥️ Dashboard Preview

![HR Analysis Dashboard](Hr%20Analysis%20Dashboad%20.png)

## 🎯 Project Objective

Employee attrition is an important HR metric that can affect workforce planning, recruitment, and employee retention.

The objective of this project is to explore **where employee attrition occurs and how it varies across different employee characteristics**.

### Key Questions Explored

* 👥 How does attrition vary across different **age groups**?
* 💰 Which **salary ranges** show different attrition levels?
* 🎓 How does attrition vary by **education level**?
* ⏳ How does attrition change with **working years**?
* ⚥ How does attrition differ by **gender**?
* 🏢 Which **departments** show different attrition patterns?

## 📊 Key HR Metrics

The dashboard includes important KPIs such as:

* **Total Employees**
* **Employees Who Left**
* **Attrition Rate**
* **Average Salary**
* **Average Working Years**

### Attrition Rate

```text
Attrition Rate =
Employees Who Left ÷ Total Employees × 100
```

This provides a more meaningful comparison than looking only at the number of employees who left.
